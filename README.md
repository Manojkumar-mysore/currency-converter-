💱 Simple Currency Converter

A small Python project that converts amounts between currencies using the "currency_converter" package. This project helped me practise Python and work with an external package.

✨ Features

- Convert an amount from one currency to another
- Use the "currency_converter" Python package
- Run the program locally with Python

🛠️ Technologies Used

- Language: Python 3
- Package: "currency_converter"

📋 Requirements

- Python 3
- pip

🚀 Installation and Setup

1. Clone or download this repository.

2. Open the project folder in your terminal.

3. Install the required package:
   
   pip install currencyconverter

4. Run the main Python file:
   
   python main.py
   
   Replace "main.py" with your actual Python filename if it is different.
